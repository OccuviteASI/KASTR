Low-latency video over Media over QUIC, served with the COOP/COEP isolation the WebCodecs audio path requires. Publish cameras, a screen or window, or an RTSP feed — each as its own broadcast — and switch between them from a single view.

Go Live

Go Live Watching and publishing on one page. Stream list plus grid or program view; per-stream volume and mute. Share opens the native publish panel — cameras, screen, RTSP, files — with a full-framerate self-view under My streams.

Relay serverhost it here Run a MoQ relay on this machine with the bundled moq-relay — for an isolated network, or when the shared relay is unreachable.
Pages point at the relay shown in the header. If a page sits at “Searching for live broadcasts…”, the relay has no live broadcasts or is unreachable — that is the relay, not the page. Change the Relay URL field on any page to override, or the --relay flag (or kastr.ini) to change it everywhere.
