Federation

Join this relay to a hub relay on another KASTR machine — rooms and streams then flow across all federated relays. A hub that requires access codes also needs its federation code (set on the hub's Relay page, Access codes block); this relay presents it and the hub mints the relay-to-relay token. By default this KASTR also pulls its updates from the hub's KASTR — the federation master — every hour, so one machine is the fleet's single update point. The hub's certificate is pinned by its fingerprint once learned (0.16.0) and re-learned when the hub restarts; until then the link is trusted without verification.

Spokes join with this relay's address and the federation code from the Access codes block. Spokes that pull updates follow this KASTR's version.

Move hub duties to this relay?

This relay is connected to the hub . Making it the hub will:

  • copy the hub's rooms, room groups and chat history here, with its access codes and kicks (everyone keeps their codes);
  • tell every relay connected to that hub to connect here instead;
  • turn hub duties off on , which keeps running as an ordinary relay connected to this one.

Shared files and recordings stay on the old hub. This relay's own access codes are replaced by the hub's.

Make the standby hub?

It keeps a copy of this hub's rooms, access codes, kicks and chat. If this hub is unreachable for 2 minutes (and a spoke agrees, or after 5 minutes alone) it takes over; when this hub is back it hands everything back by itself.
